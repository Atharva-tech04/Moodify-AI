## Abstract
Moodify AI is a React + Flask prototype for exploring music tracks using audio features, browsing heuristic mood categories, receiving similar-track recommendations, and viewing analytics. It cleans track metadata and numerical features, generates four transparent mood proxies from energy and valence, compares classifiers and clustering algorithms, and evaluates recommendations using a proxy relevance protocol. Since the mood labels are generated by rules rather than listeners, the results do not establish human emotion-recognition accuracy.

## 1. Introduction
Music discovery systems help listeners navigate large catalogs beyond popularity rankings. This project integrates data cleaning, audio-feature-based recommendation, model evaluation, and an interactive browser interface. Objectives: clean and validate the dataset; compare classification, clustering, and recommendation approaches with appropriate metrics; deploy a cross-platform React UI backed by Flask; and document limitations and reproducibility.

## 3. Dataset and cleaning
Dataset source: [insert verified repository and license]. Required fields include track ID, title, artist, genre, danceability, energy, valence, acousticness, instrumentalness, speechiness, liveness, tempo, and popularity. The pipeline renames source columns, removes missing IDs and duplicate IDs, removes rows with missing essential metadata, coerces numeric features, imputes missing values with medians, clips bounded features, clips tempo to a plausible range, and converts popularity from 0–100 to 0–1.

Mood proxy rules: if energy ≥ 0.70, label Intense when valence < 0.45 and Happy otherwise. If energy < 0.70 and valence < 0.35, label Sad; otherwise label Calm. These are not listener-annotated emotional labels.

## 4. Methodology
Architecture: React/Vite frontend, Flask REST API, pandas/NumPy cleaning, scikit-learn models, and Recharts visualization. Recommendation options are cosine similarity, K-nearest neighbors, and popularity baseline. Classification uses a stratified 75/25 split and reports accuracy, macro precision, macro recall, macro F1, confusion matrix, and runtime. Clustering compares K-Means and Agglomerative with silhouette score on a deterministic sample. Recommendation evaluation treats same-mood tracks as proxy-relevant and reports Precision@10, Recall@10, and NDCG@10 over sampled query tracks.

## 7. Limitations and future work

Future work should gather listener annotations or interactions, use user/track-separated evaluation, compare collaborative approaches, and run usability tests.
